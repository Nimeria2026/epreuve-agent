# 08_publications

Les résultats publiés, un dossier par publication, nommé `AAAA-MM-JJ_sujet/`. Chaque publication
contient au moins sa fiche de run, ses résultats bruts et son rapport.

Une publication est figée : on ne la modifie jamais. Une erreur découverte après coup donne une
nouvelle publication, qui cite l'ancienne et explique la correction.

Les runs de travail n'entrent pas ici : ils restent dans `99_local/`, hors git.
Rempli à partir de : étape 3.
