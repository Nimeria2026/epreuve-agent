# Publication 2026-10-28, premier_post

Écrite par `make publier` au commit `c765b07`, protocole `protocole-v1`. Elle ne se modifie
jamais : une erreur donne une nouvelle publication, qui cite celle-ci.

- `manifeste.json` : les 93 runs qui fondent ses chiffres (socle 14, tau2 7, temoin 72), leur rôle et
  leurs empreintes ;
- `donnees.json` : les chiffres, calculés sur ces runs ;
- `runs/` : chaque run réduit à ses tâches publiques, sans les journaux du candidat ; sa fiche
  ne liste que ces tâches, l'empreinte du jeu restant celle du jeu entier ;
- `cachees.json` : la part des tâches non publiées, en comptes par run, sans nom de tâche.
