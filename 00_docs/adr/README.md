# Décisions d'architecture (ADR)

Un ADR consigne une décision qui change la structure du dépôt ou une règle technique durable. Il
est obligatoire pour toute modification d'`arborescence.toml`.

Quand en écrire un : après un vrai problème rencontré, avec sa date et le fichier ou la commande
en cause. Un confort ou une préférence ne suffit pas.

Nommage : `AAAA-MM-JJ_NNNN_titre.md`, numéros continus à partir de 0001. Modèle :
`modele_adr.md`. Un ADR accepté ne se modifie plus ; un nouvel ADR le remplace et le cite.
