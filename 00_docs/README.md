# 00_docs

La documentation du projet, en dehors des fichiers de pilotage de la racine.

- `sources/` : documents de référence et veilles, datés (`AAAA-MM-JJ_nom.md`). Une source ne se
  réécrit pas après coup ; une mise à jour donne un nouveau fichier daté. Ce sont des notes de
  travail : elles restent dans l'atelier privé et ne sont pas publiées.
- `adr/` : les décisions d'architecture.
- `protocole/` : le protocole de mesure, figé par version (étiquette git `protocole-v1`).
- `manuels/` : les trois documentations vivantes (ADR 0012) : l'utilisation de l'Épreuve d'agent,
  le guide remis à l'entreprise avec son rapport, l'argumentaire pour répondre aux entreprises.
  Elles se corrigent dès qu'une commande ou une règle change, et restent dans l'atelier.
